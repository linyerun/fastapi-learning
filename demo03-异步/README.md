# 笔记记录
- 协程函数(coroutine Function)：使用『async关键字』修饰的函数，就是协程函数。
- 协程对象(coroutine Object)：调用『协程函数』，就会得到『协程对象』。
- 将协程对象交给asyncio.run()，asyncio.run()会将协程对象包装成一个任务交给事件循环。
- 使用asyncio.create_task()方法向事件循环中添加任务，从而实现多个任务异步执行。
- asyncio.gather方法可以把多个协程对象丢给事件循环，并在全部执行完后，一次性拿到所有结果。
- await关键字, 用于修饰协程对象
  - 如果在执行该对象中的代码时，遇到了【await I/O操作】（需要等待外部资源返回结果的操作）例如：网络请求、文件读写等，那 CPU 的控制权就会交给事件循环。事件循环会去调度循环中的其他任务（如果有的话）。
  - 如果该对象中的代码，不包含任何【await I/O操作】。例如：print打印、数学计算、逻辑计算等。此时事件循环拿不到 CPU 控制权，无法调度循环中的其他任务，不会发生任务切换。
